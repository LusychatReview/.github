**What is Lusychat?**

</div>

Lusychat is an 18+ AI character platform. You browse a community library or build your own character, then chat and generate images. Not a blank chatbot. A character with a name, a look and a personality.

Pick someone from the public library or create your own: name, description, greeting. The chat stays tied to that character. Images are generated from the same setup and spend LusyCoins. There is a free tier with a daily message limit. Paid plans raise the limit and add coins.

It runs in the browser. An Android app is also listed on the site. 18+ only.
