## What it is

[Lusychat](https://chubby-gf.com/lusychat) is built around fictional characters. You pick someone from the public library or create a character with a name, look, personality and opening line. Chat stays tied to that character. Images are generated from the same setup and spend LusyCoins.

It runs in the browser. An Android app is also listed on the site.

## What you can do

- **Chat.** Talk to a chosen or custom character. The free tier includes a daily message allowance.
- **Create a character.** Name, personality, description and greeting.
- **Browse.** A community library of characters.
- **Images.** Generate stills of a character. Coin cost depends on the plan.
- **Models.** Paid tiers can switch between different chat models.

Prices and coin grants change. Check the live plan page before you pay.

## Who it is for

Use it if you want community characters, your own character, and pictures in the same place. Skip it if you want therapy or a general work chatbot.

[Open Lusychat](https://chubby-gf.com/lusychat)

## Pricing

There is a free tier with a limited number of daily messages. Paid plans add more messages, larger context and a monthly LusyCoins allowance for images. Open the upgrade screen and read the current numbers.

## Pros and cons

**Pros**

- Character library and a creator.
- Chat and images in one product.
- Free tier to try before paying.
- Browser, plus an Android app listed on the site.

**Cons**

- Images spend coins.
- Community characters vary in quality.
- Adult product. Do not put sensitive personal data into the chat.
- Not a substitute for a real person or for professional help.
