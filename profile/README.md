**What is Lusychat**

Lusychat is an 18+ AI character platform. You pick a companion from the library or build your own, then chat and generate images. Each character has a name, a look and a personality, so the thread is not a blank bot.

Create a character or start from a community one. Talk in the browser. Generate pictures of that character when you want them. Images spend LusyCoins. There is a free tier with a daily message limit. Paid plans raise the limit and add coins.

It runs in the browser. An Android app is also listed on the site.
